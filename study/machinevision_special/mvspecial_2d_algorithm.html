2D Rule-based 검사 알고리즘

1. 이 챕터에서 다루는 내용

  • Rule-based(규칙 기반) 검사는 사람이 정의한 명확한 규칙(임계값·형상 조건)으로 영상 내 결함 유무를 판정하는 전통적인 영상처리 방식으로, 데이터로부터 스스로 패턴을 학습하는 딥러닝 기반 검사와 대비되는 개념
  • Final Exterior Inspection(외관검사) 장비 대부분은 지금도 이 방식을 기본 골격으로 사용함 — 이유는 결함의 기준이 명확하고, 연산이 가벼워 처리속도가 빠르며, 판정 근거를 사람이 설명할 수 있기 때문(Explainability)
  • 이 알고리즘은 하나의 기법이 아니라, 영상 획득부터 최종 판정까지 이어지는 일련의 처리 파이프라인으로 이해해야 함 — 각 단계는 독립적이지 않고, 앞 단계의 처리 품질이 다음 단계의 정확도에 그대로 이어짐
  • 이 페이지는 전체 흐름과 각 단계의 개념을 개관하고, 각 단계의 알고리즘 원리는 하단의 세부 챕터 링크를 통해 심화 학습할 수 있도록 구성함

2. 세부 챕터 (심화 학습)

각 단계가 "왜 그렇게 동작하는가"까지 파고들고 싶다면 아래 세부 챕터를 순서대로 학습하세요. 알고리즘의 계산 원리, 수식, 실제 동작 예시를 다룹니다.

3. 결함 유형별 검출 전략 요약

결함 유형형태·밝기 특성주요 Feature검출 기법
이물 / 오염 주변 대비 어둡게 나타남, 대체로 둥근 형태 Area, Circularity 어두운 영역 이진화 + Blob 면적·원형성 필터링
스크래치 직선형, 방향성 있는 국소 밝기 변화 Aspect Ratio, Struct Factor 엣지 기반 이진화 + 직선성 팩터로 이물과 구분
얼룩 (Mura성) 넓은 영역의 완만한 밝기·색 불균일 국소 밝기 편차, 영역 대비 저주파 성분 분리 + 영역별 밝기 편차 비교
패턴 오류 정상 패턴과 형상·위치가 다름 Rectangularity, 위치 편차 Golden Template 차영상 / XOR 비교

4. Rule-based 방식의 한계와 다음 방향

  • 한계 : 조명 변화에 민감해 현장 환경이 바뀌면 임계값 재조정이 필요함, 사전에 정의되지 않은 새로운 유형의 결함에는 대응이 어려움, 저대비·미세 결함은 이진화 단계에서부터 놓치기 쉬움
  • 딥러닝 기반과의 관계 : Rule-based는 정렬·전처리와 기준이 명확한 결함 검출에 여전히 강점이 있고, 딥러닝은 복잡한 패턴이나 사람이 규칙화하기 어려운 미세 결함에 강점이 있음 — 최근 현장에서는 두 방식을 함께 쓰는 하이브리드 구조가 확산되는 추세
  • 다음 스터디 예고 : 3D 검사 알고리즘(Point Cloud 기반 정합, 높이 정보를 이용한 단차·요철·평탄도 결함 검출)을 이어서 다룰 예정
핵심 요약
Rule-based 2D 알고리즘은 지금도 대부분의 Final Exterior Inspection 장비에서 핵심 로직으로 동작합니다. 딥러닝은 이를 완전히 대체하기보다, 놓치기 쉬운 영역을 보완하는 방향으로 함께 발전하고 있습니다.
