1. 공정 개요

3단계 공정 구조

  • 디스플레이 제조는 크게 어레이(Array) → 셀(Cell) → 모듈(Module) 3단계로 구성된다.
  • 어레이: TFT 기판 제작. 반도체 공정과 유사한 포토리소그래피·식각·증착 과정.
  • 셀: LCD는 액정 주입 및 두 기판 합착, OLED는 유기물 증착과 봉지 공정 수행.
  • 모듈: 편광판, 드라이버IC, BLU(LCD), 커버유리 등을 조립하여 완성품 패널 완성.

2. 어레이(TFT) 공정

공정 흐름

  • 세정 → 금속 증착(스퍼터링) → 포토리소그래피 → 식각 → 절연막 증착 → 반복 (보통 5~7 mask layer).
  • 목표: 각 픽셀에 TFT(스위칭 소자) + 투명전극(ITO) 형성.
  • 핵심 장비: 스퍼터링 장비, CVD(화학기상증착), 포토레지스트 코터, 식각기(드라이/웨트).
  • LCD와 OLED 어레이 공정은 유사하나, OLED는 TFT 위에 ITO 양극까지 추가 형성.
  • 공정 중 AOI(자동광학검사)로 단락·미연결·이물 등 결함을 실시간 검사.

포토리소그래피 상세

  • PR 도포: 기판에 감광성 수지(Photo Resist) 스핀 코팅.
  • 노광: 마스크(Reticle)를 통해 UV 또는 EUV 광원으로 패턴 전사.
  • 현상: 노광된 영역의 PR 제거(양성 PR 기준) → 원하는 패턴 남김.
  • 식각: 드라이(플라즈마) 또는 웨트(화학액) 방식으로 하부막 제거.
  • PR 제거(Stripping): 잔여 PR 세정 제거 후 다음 층 공정 진행.

3. 셀(Cell) 공정 — LCD vs OLED

LCD LCD 셀 공정

  • 배향막 도포: 폴리이미드(PI) 배향막을 TFT 기판과 CF 기판 양쪽에 도포.
  • 러빙(Rubbing): 천 롤러로 배향막 표면을 문질러 액정 분자의 초기 배향 방향 설정.
  • 실런트 도포: 패널 테두리에 에폭시 실런트 도포 — 두 기판을 봉지하고 액정 누출 방지.
  • 합착: TFT 기판 + CF 기판을 정밀 정렬 후 가압 합착.
  • 액정 주입(ODF): One Drop Fill 방식 — 합착 전 기판 위에 액정 일정량 적하, 진공 합착 시 퍼짐.
  • UV 경화: 실런트에 UV 조사하여 경화 → 패널 봉지 완료.
  • ODF 방식: 대면적 패널에서 액정 낭비 최소화, 균일한 셀 갭(Cell Gap) 유지.

OLED OLED 셀 공정

  • FMM 마스크 세팅: 인바 합금 Fine Metal Mask를 TFT 기판 위에 정밀 정렬.
  • 유기물 열증착(Evaporation): 진공 챔버(10⁻⁶ torr 이하)에서 HIL/HTL/EML/ETL/EIL 순 증착.
  • 음극 증착: Al 또는 Mg:Ag 합금 증착으로 음극 형성.
  • 봉지(Encapsulation): 리지드 → 봉지 유리 합착, 플렉시블 → TFE 무기/유기 다층 박막.
  • 절단(스크라이빙): 대형 원장 기판을 개별 패널 크기로 절단.
  • 증착 진공도: 10⁻⁶ torr 이하. 수분·파티클 1개도 Dark Spot의 직접 원인이 됨.
  • 봉지 요구 사양: WVTR 10⁻⁶ g/m²/day 이하 — 디스플레이 공정 전체에서 가장 까다로운 스펙 중 하나.

4. 모듈(Module) 공정

LCD LCD 모듈 공정

  • 편광판 부착 (전면·후면 각 1장, 흡수축 방향 수직 교차).
  • 드라이버IC(DDI) 본딩: COG(Chip-On-Glass) 또는 COF(Chip-On-Film) 방식.
  • PCB 연결: FPC(연성 회로기판)로 드라이버IC와 메인 보드 연결.
  • BLU 조립: 반사판 + 도광판 + 확산판 + 프리즘 시트 + LED 바 순으로 적층 조립.
  • 터치패널 OCA 접착: 에어갭 없이 완전 합착(Full Lamination).
  • 커버유리 합착 및 최종 검사.

OLED OLED 모듈 공정

  • 원편광판(Circular Polarizer) 부착 1장 — 외부광 반사 방지용 (Lambda/4 + Linear Polarizer 조합).
  • COF 드라이버IC: 플렉시블 패널의 특성상 COF 방식으로 벤딩 영역에 실장.
  • FPCB 연결: 유연한 연성 기판으로 패널 배면으로 벤딩.
  • 터치 OCA 합착: 유리 또는 폴리머 터치 레이어를 OCA로 부착.
  • 커버유리 또는 UTG(Ultra-Thin Glass, 두께 30~100μm) 합착.

5. 검사 공정

단계별 검사 항목

  • 어레이 검사: TFT 전기 특성 검사(프로브 접촉), 인라인 AOI(자동광학검사)로 단락·Open·이물 확인.
  • 셀 검사: 전 픽셀 ON/OFF 점등 검사, 화질 검사(Mura·Dark Spot·Line 결함 확인).
  • 모듈 검사: 색도·휘도 측정, 터치 응답 확인, 영상 신호 입력 후 화질 최종 확인.

주요 불량 유형

불량 유형 설명 주 발생 공정
Dot 결함 특정 픽셀이 항상 켜지거나(Bright Dot) 꺼진(Dark Dot) 점 결함 어레이, 셀
Line 결함 행 또는 열 전체가 불량 — TFT 게이트/데이터 라인 단선 어레이
Mura 휘도 불균일. 국소적 밝기 차이가 면 얼룩으로 보임 셀, 모듈
Dark Spot OLED 유기물 열화 — 수분/파티클 침투로 발광층 손상 OLED 셀 (봉지 불량)
클린룸 필수: 디스플레이 공정에서 파티클 1μm 크기 하나가 Dark Spot이나 단락으로 이어질 수 있어, 반도체 수준의 클린룸(Class 1~10) 환경이 필수다. 현대 팹에서는 AOI + AI 딥러닝 기반 불량 자동 분류 시스템 도입이 확산되고 있다.
