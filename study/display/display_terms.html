1. 화질 성능 지표

휘도 (Luminance / Brightness)

  • 단위: cd/m² (칸델라/제곱미터), 통칭 nit
  • 화면 밝기를 나타내는 가장 기본적인 지표
  • 일반 LCD: 250~500nit, HDR TV: 1,000nit+, Micro LED: 10,000nit+
  • 야외 직사광선(약 100,000lux) 환경에서도 시인성 확보를 위해 고휘도 필요

명암비 (Contrast Ratio)

  • 가장 밝은 화이트(White) 대 가장 어두운 블랙(Black)의 밝기 비율
  • 정적(Static) 명암비: 동시에 표시되는 화이트:블랙 비율. OLED는 픽셀 개별 OFF → 이론상 무한대
  • 동적(Dynamic) 명암비: BLU 로컬 디밍 활용 시 시간차 최대:최소 비율. 마케팅 수치로 사용
  • 일반 IPS-LCD: 1,000:1, VA-LCD: 3,000~6,000:1, OLED: 무한대(∞:1)

색재현율 (Color Gamut)

  • 표시 가능한 색의 범위. 기준 색 공간(Color Space) 대비 커버리지(%)로 표현
  • sRGB: PC·인터넷 표준 (=NTSC 72%). 일반 용도
  • DCI-P3: 영화 산업 표준. sRGB보다 25% 넓음. 스마트폰·전문가 모니터 기준
  • BT.2020: HDR 방송 표준. DCI-P3보다 훨씬 넓음. 현재 기술로 달성 어려움
  • QD(양자점) 기술이 색순도 향상에 핵심 역할

응답속도 (Response Time)

  • 픽셀이 특정 명도에서 다른 명도로 변화하는 데 걸리는 시간 (단위: ms)
  • GtG(Gray-to-Gray): 중간 회색 간 변환 시간 — 실사용과 가장 관련 깊음
  • TN: 1ms, IPS: 4~8ms, OLED: 0.1ms 미만
  • 응답속도 느리면 빠른 움직임에서 잔상(Motion Blur) 발생

주사율 (Refresh Rate)

  • 1초 동안 화면을 갱신하는 횟수 (단위: Hz)
  • 60Hz(일반) → 120Hz → 144Hz → 165Hz → 240Hz (게이밍) 순으로 발전
  • 높을수록 부드러운 움직임 — 특히 빠른 게임, 스크롤에서 체감 큼
  • 가변 주사율(VRR): AMD FreeSync / NVIDIA G-Sync — GPU 출력에 맞춰 주사율 동기화, 화면 끊김 방지

PPI (Pixels Per Inch)

  • 1인치(2.54cm)당 픽셀 수. 높을수록 섬세하고 선명한 화질
  • 스마트폰: 400~600PPI (눈에 인식되는 픽셀 경계 없음)
  • 일반 모니터(27인치 4K): 163PPI, TV(55인치 4K): 80PPI
  • VR 헤드셋: 3,000+PPI 필요 — 눈앞 몇 cm 거리에서 보기 때문

2. 공정·구조 용어

TFT (Thin Film Transistor)

  • 각 픽셀의 ON/OFF를 독립 제어하는 박막트랜지스터
  • a-Si(비정질 실리콘): 저렴, 낮은 이동도. 대면적 LCD TV용
  • LTPS(저온 폴리실리콘): 고이동도, 작은 트랜지스터 → 고해상도·고주사율. 스마트폰 OLED용
  • Oxide(IGZO 등): 낮은 누설전류 → AOD에 유리. 태블릿·TV OLED용
  • LTPO: LTPS + Oxide 혼합 → 가변 주사율(1~120Hz) 구현

BLU (Back Light Unit)

  • LCD 패널에 빛을 공급하는 광원부 모듈
  • 구성: LED 광원 → 도광판(LGP) → 반사 시트 → 확산 시트 → 프리즘 시트
  • 직하형(Direct): LED가 패널 바로 뒤에 배치. 로컬 디밍 가능, 두께 증가
  • 엣지형(Edge): LED가 측면에 배치. 얇은 두께, 로컬 디밍 제한

ODF (One Drop Fill)

  • 합착 전 TFT 기판 위에 액정을 정량 적하(Drop)하는 방식
  • 기존 진공 주입 방식 대비 빠른 공정, 낮은 낭비 — 현재 표준 방식
  • 적하량 정밀 제어가 Mura 불량에 직결 → 공정 관리 핵심 포인트

COG / COF (드라이버 IC 실장)

  • COG(Chip-On-Glass): 드라이버 IC를 유리 기판에 직접 이방성 도전 필름(ACF)으로 실장. 베젤 최소화에 유리
  • COF(Chip-On-Film): 드라이버 IC를 플렉시블 필름(FPC)에 실장 후 패널에 연결. 폴더블·곡면에 적합
  • 최근 폴더블 스마트폰은 대부분 COF 또는 내장형(On-Cell) 방식 채택

OCA (Optical Clear Adhesive)

  • 광학 투명 접착제 — 커버 유리·터치 패널·편광판 접합에 사용
  • 광투과율 99%+, 굴절률 일치 설계로 반사 최소화
  • 에어갭 제거(Full Lamination) → 야외 시인성·터치감 대폭 향상

TFE (Thin Film Encapsulation)

  • 플렉시블 OLED 봉지(Encapsulation) 방식 — 유리 봉지 대신 박막 적층
  • 무기막(SiNx, Al2O3) + 유기막(Parylene, 아크릴) 교대 적층으로 수분·산소 차단
  • WVTR(수분 투과율) < 10⁻⁶ g/m²/day 이하 달성 필요
  • 유리 봉지(Frit) 대비 얇고 유연 → 플렉시블·폴더블 OLED 핵심 기술

FMM (Fine Metal Mask)

  • OLED R·G·B 유기물 진공 열증착(Vacuum Thermal Evaporation) 시 패터닝에 사용하는 마스크
  • 인바(Invar) 합금 (Fe-Ni 36%) — 열팽창 계수 극소화 필수
  • 고해상도화(500PPI+)를 위해 마스크 개구부 미세화가 핵심 과제
  • 삼성·LG는 레이저 식각·전기 주조로 제작. 대면적 FMM 처짐 문제 → OLED TV 제조 난관

3. 불량·품질 용어

Mura (무라 / 얼룩)

  • 디스플레이 면내 휘도 또는 색도의 불균일 — 육안으로 "얼룩"처럼 보임
  • 원인: 배향막 불균일, 합착 압력 편차, BLU 광 분포 불균형, 액정 적하량 편차 등
  • 검출: AOI + 다크룸 육안 검사 조합. AI 기반 Mura 검출 도입 확산
  • 등급 분류: CF(Color Filter) Mura, BLU Mura, Compression Mura 등

Dark Spot (다크 스팟)

  • OLED에서 유기물이 수분·산소에 노출되어 열화, 발광이 되지 않는 검은 점
  • 봉지(Encapsulation) 결함이 주 원인 — 핀홀, 크랙, 이물 혼입
  • 시간이 지남에 따라 점이 커지는 성장성 불량
  • 방지: TFE 품질 관리, 클린룸 청정도 유지, 봉지재 수분 차단 성능 확보

Dot Defect / Line Defect (점·선 결함)

  • Dot Defect(점 결함): 특정 픽셀이 항상 켜지는(Hot pixel) 또는 꺼지는(Dead pixel) 상태
  • 원인: TFT 트랜지스터 결함, ITO 전극 단락/단선, 이물 혼입
  • Line Defect(선 결함): 특정 행 또는 열 전체가 밝거나 어두운 상태
  • 원인: 드라이버 IC 불량, 게이트/데이터 배선 단선, ACF 접촉 불량
  • 출하 기준: 결함 픽셀 수·위치·밀도에 따른 등급 판정 (ISO 13406-2 등 참조)

번인 (Burn-in)

  • 동일 이미지를 장시간 표시 시 화상(잔상)이 화면에 영구적으로 남는 현상
  • OLED에서 발생: EML(발광층) 유기물의 차등 열화 — 밝게 오래 켜진 픽셀이 더 빨리 열화
  • LCD는 번인 없음 (유기물 미사용)
  • 완화 방법: 픽셀 이동(Pixel Shift), 화면 보호기 자동 실행, 저밝기 운용, LTPO로 저주사율 유지
  • 2024년 기준 스마트폰 OLED는 일반 사용 패턴에서 실질적 번인 위험 낮음

4. 기타 주요 용어

HDR (High Dynamic Range)

  • 높은 명암비와 넓은 색영역으로 더 풍부하고 현실감 있는 화질 구현
  • HDR10: 오픈 표준, 정적 메타데이터, 1,000nit 피크 기준. 가장 범용
  • Dolby Vision: 동적 메타데이터, 최대 10,000nit 지원, 씬별 최적화. 프리미엄 규격
  • HLG(Hybrid Log-Gamma): SDR 호환 HDR. 방송용 표준 (BBC·NHK 공동 개발)
  • HDR 구현 조건: 고휘도 + 넓은 색역 + 적절한 콘텐츠 메타데이터 동시 필요

PWM 디밍 vs DC 디밍

  • PWM(Pulse Width Modulation) 디밍: 백라이트를 고속 ON/OFF 반복하여 밝기 조절 (듀티비로 제어)
  • 저밝기에서 ON/OFF 주파수가 낮아지면 육안으로 깜빡임(Flicker) 인지 → 눈 피로·두통 원인
  • 60Hz 미만 PWM은 민감한 사용자에게 체감 가능
  • DC 디밍: 전류를 직접 조절하여 밝기 제어 — 깜빡임 없음. 색조 변화 가능성 있음
  • 최근 고급 스마트폰: 저밝기 구간 PWM 주파수 2,160Hz 이상으로 플리커 체감 최소화

LTPO (Low Temperature Polycrystalline Oxide)

  • LTPS TFT(고성능 구동)와 Oxide TFT(저누설 유지)를 동일 기판에 혼합 구성
  • 주사율을 콘텐츠에 따라 1Hz ~ 120Hz로 동적 제어 → 소비전력 최대 40% 절감
  • 정적 화면(지도, 텍스트): 1~10Hz 유지, 빠른 화면: 120Hz로 즉시 전환
  • 2021년 iPhone 13 Pro부터 적용, 현재 플래그십 스마트폰 표준 기술

AOI (Automated Optical Inspection)

  • 자동광학검사 — 고해상도 카메라와 조명으로 불량을 자동 검출하는 인라인 검사 장비
  • 검출 항목: 이물, 스크래치, 패턴 결함, Mura, 얼라인 오차, 인쇄 불량 등
  • 최근 트렌드: 딥러닝(CNN) 기반 AI 결함 분류 시스템 도입 — 사람 판별 어려운 미세 결함 검출
  • 검사 속도·정확도가 라인 생산성에 직결 — 오검(False Positive) 최소화 중요
