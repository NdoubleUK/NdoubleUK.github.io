디스플레이 원리

LCD · OLED · 색 재현 · 픽셀 구동 방식의 핵심 원리를 레이어 구조와 함께 이해합니다

1. LCD 작동 원리

LCD
  • LCD(Liquid Crystal Display)는 스스로 빛을 내지 않음 — BLU(백라이트 유닛)의 빛을 액정층으로 제어하는 투과형 디스플레이
  • 편광판 ① → 액정층 → 편광판 ② 구조. 액정에 전압이 없으면 빛이 차단되거나 통과 (모드에 따라 다름 — TN/IPS/VA)
  • 전압 인가 시 액정 분자 배열이 변해 빛의 투과량 조절 → 픽셀별 명암 제어
  • 컬러필터(R·G·B)를 통과시켜 색 표현 — 백색광을 3원색으로 분리하는 방식
  • 백라이트: 과거 CCFL(냉음극 형광등) → 현재 LED 엣지형 / 직하형(Local Dimming 가능)
핵심 구조: BLU → 하부 편광판 → TFT 기판(전극·액정층 포함) → 컬러필터 기판 → 상부 편광판 → 시청자. 두 편광판은 90° 직교 배치가 기본.

2. OLED 작동 원리

OLED
  • OLED(Organic Light-Emitting Diode): 유기물에 전류를 흘리면 자체 발광 — 백라이트 불필요
  • 구조: 기판 → 양극(ITO) → HIL(정공주입층) → HTL(정공수송층) → EML(발광층) → ETL(전자수송층) → EIL(전자주입층) → 음극(Al)
  • 발광 원리: 양극에서 정공(+), 음극에서 전자(-) 주입 → EML에서 결합 → 엑시톤(Exciton) 생성 → 빛 방출
  • R·G·B 각 서브픽셀에 다른 유기물 사용 (FMM 증착 방식) 또는 White OLED + 컬러필터 방식 (대형 패널)
  • 완전한 블랙 표현 가능 (개별 픽셀 OFF), 명암비 이론상 무한대 — LCD 대비 압도적인 화질
핵심 원리: 전자와 정공이 EML에서 만나 엑시톤을 형성하고, 엑시톤이 기저 상태로 전이할 때 에너지가 빛으로 방출됩니다. 유기물 종류에 따라 발광 파장(색)이 결정됩니다.

3. 색 재현 원리

  • 모든 디스플레이는 R·G·B 서브픽셀 조합으로 색 표현 (가산혼합 원리 — 세 색이 합쳐지면 흰색)
  • 색재현율(Color Gamut): sRGB / DCI-P3 / BT.2020 기준으로 표현 가능한 색의 범위를 정의. 수치가 높을수록 더 넓은 색공간 커버
  • 컬러필터(LCD): 백색광을 R·G·B로 분리 — 광효율 손실 발생 (대부분의 빛이 필터에서 흡수됨)
  • OLED: R·G·B 유기물이 직접 발광 — 순도 높은 색표현 가능, 광효율 우수
  • Quantum Dot(QD): BLU의 청색광을 QD 필름이 변환하여 순도 높은 R·G 생성 → 색재현율 향상 (QD-OLED, QD-LCD 모두 적용)
색재현율 기준: sRGB (일반 모니터 표준) < DCI-P3 (영화관 / 프리미엄 스마트폰) < BT.2020 (차세대 방송 표준). OLED는 DCI-P3 기준 100%+, Micro LED는 BT.2020까지 커버 가능.

4. 픽셀 구동 방식 (PM vs AM)

  • PMOLED (Passive Matrix): 행·열 스캔으로 순차 구동. 소규모·저해상도 웨어러블용. 회로 단순하나 고해상도 시 소비전력 급등
  • AMOLED (Active Matrix): 각 픽셀에 TFT(박막트랜지스터) 내장 → 독립 구동. 대형·고해상도·고주사율 패널에 필수
  • TFT 종류 — a-Si (비정질 실리콘): 공정 단순, 원가 저렴. 전자 이동도 낮아 (약 1 cm²/Vs) 스마트폰 OLED에는 부적합
  • TFT 종류 — LTPS (저온폴리실리콘): 이동도 높음 (50~100 cm²/Vs). 스마트폰 AMOLED에 주로 사용. 공정 온도 400°C 이하
  • TFT 종류 — Oxide (IGZO): In-Ga-Zn-O 산화물 반도체. 균일성 우수, 누설 전류 낮음. 대형 TV·모니터용 OLED/LCD에 적합
항목 PMOLED AMOLED
구동 방식 행·열 순차 스캔 (패시브) 픽셀 내 TFT 독립 구동 (액티브)
TFT 유무 없음 픽셀마다 TFT (2T1C 이상)
해상도 한계 저해상도 (128×128 수준) 고해상도 (4K+ 가능)
소비 전력 해상도 증가 시 급증 상대적으로 효율적
주요 용도 스마트 밴드, 간단 기기 UI 스마트폰, TV, 모니터
LTPS vs Oxide: LTPS는 높은 이동도 덕분에 스마트폰 소형 고해상도에 유리. Oxide(IGZO)는 대형 패널에서 균일한 특성을 보여 55인치 이상 TV 패널에 주로 채용.
